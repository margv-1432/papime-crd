# Capítulo I. Entrega B02

La fuente editable es `libro/capitulos/01-territorio.Rmd`, con bibliografía común y seis recursos individuales. El capítulo PDF se entrega en `entregas/pdf/PAPIME-B02-capitulo-I.pdf`; el avance integrado en `PAPIME-libro-avance-B02.pdf`.

Abrir `entregas/web/index.html` conservando la carpeta completa. Las figuras y sus tablas se pueden abrir individualmente desde `entregas/web/recursos`. El PDF incluye sus equivalentes estáticos. La carpeta web es una entrega local; no se ha habilitado GitHub Pages.

Reproducción: `Rscript scripts/compilar.R todo` desde la raíz. Datos, fuentes, decisiones y resultados de pruebas se describen en `seguimiento/REPRODUCIBILIDAD_B02.md`, `VERIFICACION_B02.md` y `ESTADO.md`.
